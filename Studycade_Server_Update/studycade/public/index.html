Save study Markdown files to your account, organized in folders you name. Only your approved account can open its saved files. Headings become a clickable outline, and you can mark each section reviewed and set your confidence to Green, Yellow, or Red.

How to use it

  1. Ask an AI to make a study file using the prompt below, or use a Markdown file you already have.
  2. Save its complete response as a .md file.
  3. Enter a folder name, then choose the file or drag it here. It uploads to your account and appears below for later use.
  4. Read each section, try the recall questions before revealing answers, and mark your confidence.

SETS & CARDS
Import a flashcard set
From Quizlet, export with a tab between term and definition and a new line between cards. Paste the copied text below. CSV and semicolon-separated exports also work.
Math: use \(x^2\) for inline equations or \ce{H2O} inside math. For visual entry, place your cursor in a term or definition and use the math button below.
4–2,000 distinct terms. Import one set at a time.

  
VISUAL MATH ENTRY
Insert an equation
Type as you would in a math calculator. Use the on-screen keyboard for fractions, roots, and powers. The equation is inserted at your cursor as LaTeX.

  
YOUR DATA
Export your sets
Download a JSON copy of the sets you own and your progress. Built-in course sets are already part of the app.
